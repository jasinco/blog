# Recursive
## Fibonacci Series
```c
int fib(int a, int b, int n, int sum) {
  if (n <= 0) {
    return sum;
  }
  sum += a;
  printf("%d ", a);
  b = a + b;
  a = b - a;
  return fib(a, b, n - 1, sum);
}
```

### Function Call counts
$$
f(1) = 1, f(2) = 1, f(n) = f(n-1) + f(n-2) \
3: 1 + 2 \
4: (1 + 2) + 2 \
5: ((1 + 2) + 2) + (1 + 2) \
$$

$$
C(1) = 1 \
C(2) = 1 \
C(n) = C(n-1) + C(n-2) + 1 \

"let T(n) + c = C(n)" \
T(n) = T(n-1) + T(n-2) + c + 1 \
"let c = -1" \
T(n) = T(n-1) + T(n-2) \
T(1) = 2, T(2) = 2 \
T(n) = 2 * fib(n)\
C(n) - (-1) = 2 * fib(n) \
C(n) = 2 * fib(n) - 1
$$
## Hanoi Tower

one stage  
1. A to C

two stage  
1. A to B
2. A to C
3. B to C

n stage  
1. n-1 to B
2. A to C
3. n-1 to C

```c
void hanoi(int n, char A, char B, char C) {
  if (n == 1) {
    printf("m %c to %c\n", A, C);
    return;
  }
  // move n-1 from A to B
  hanoi(n - 1, A, C, B);
  printf("m %c to %c\n", A, C);
  // move n-1 from B to C
  hanoi(n - 1, B, A, C);
}
```
# Search
## Classical Binary
```c
int binsearch(int *arr, int arr_len, int target) {
  int start = 0, end = arr_len - 1;
  while (start <= end) {
    int mid = (start + end) / 2;
    start = arr[mid] > target ? start : mid + 1;
    end = arr[mid] > target ? mid - 1 : end;
    if (arr[mid] == target)
      return mid;
  }
  return -1;
}
```

## N or Greatest before N Binary
1 2 3 5 6
search for 4, should find 3

```c
int binsearch(int *arr, int arr_len, int target) {
  int start = 0, end = arr_len - 1, ans = -1;
  while (start <= end) {
    int mid = (start + end) / 2;
    if (arr[mid] == target)
      return mid;
    else if (arr[mid] < target) {
      ans = mid;
      start = mid + 1;
    } else
      end = mid - 1;
  }
  return ans;
}
```
